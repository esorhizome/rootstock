# 04 · Physics for e-fashion

Physics where circuits meet fabric. This branch exists because a garment is a harder home for electronics than a workbench: thread resists, bodies bend, batteries ride along, and light has to look lovely rather than merely on. Each of those is physics — the friendly, checkable kind — and each one repays a five-minute page with better-looking, longer-living clothes.

This is the branch closest to *FloralFight*'s heart: FLORA is a bioluminescent flower with fiber-optic LEDs along her stem, and every make-it-real link her Lookbook will ever offer lands somewhere in this territory.
