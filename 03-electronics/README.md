# 03 · Electronics

Electricity, met properly: as push, flow, and squeeze. This branch runs from the three words themselves up through the first genuinely useful circuit arithmetic — the calculation that keeps a sewn-in LED luminous instead of cooked.

No kit is required to read any of this. When hands-on curiosity arrives, the [Falstad simulator](https://www.falstad.com/circuit/) and [FreeCircuitSim](https://freecircuitsim.com/learn/) run in the browser, free, no account — circuits you can build and watch without owning a single component.
