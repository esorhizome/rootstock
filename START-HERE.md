# Start here

This page asks for about four minutes. There is nothing to memorize on it.

## The one standing agreement

You may stop anywhere, at any point, mid-sentence if needed. Stopping is not quitting; it is how this repo is designed to be read. When you come back — tomorrow or next spring — no page will ask where you've been. Every lesson re-introduces what it needs at the top, because forgetting is expected here, planned for, and not a character flaw.

That's the whole agreement. Everything else is optional.
