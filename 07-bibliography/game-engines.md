## GDevelop

### GDevelop Wiki — Getting Started & tutorials
<https://wiki.gdevelop.io/gdevelop5/getting_started/> · <https://wiki.gdevelop.io/gdevelop5/tutorials/>
**What:** The official docs wiki: install-to-first-game walkthrough plus guided beginner projects (platformer, tank shooter).
**Cost:** ✓ free entirely (CC BY-SA — kin to this repo's own license)
**Account:** none
**Fit:** Short concrete steps; the purely-free front door to the engine AIGR's plan recommends.
*Last checked: 2026-08-20*

### GDevelop Academy ◐
<https://gdevelop.io/academy>
**What:** The official learning hub — articles, videos, in-editor guided lessons.
**Cost:** ◐ articles/most videos free; some structured courses cost ~$9–13
**Account:** none to browse
**Fit:** Video-first counterpart to the wiki.
*Last checked: 2026-08-20*

### GDevelop on YouTube
<https://www.youtube.com/@GDevelopApp>
**What:** The team's own tutorial channel and playlists.
**Cost:** ✓ free
**Account:** none to watch
*Last checked: 2026-08-20*

## Godot

### Learn GDScript From Zero (GDQuest)
<https://school.gdquest.com/courses/learn_2d_gamedev_godot_4/learn_gdscript/learn_gdscript_app>
**What:** Free interactive in-browser app teaching GDScript from absolutely nothing, with instant feedback.
**Cost:** ✓ free entirely
**Account:** none, and no install
**Fit:** The best-matched engine resource in this whole file for rootstock's readers: tiny interactive steps, no setup to lose momentum on, no login.
*Last checked: 2026-08-20*

### Godot official docs — "Step by step"
<https://docs.godotengine.org/en/stable/getting_started/step_by_step/index.html>
**What:** The engine's own patient beginner walkthrough (scenes, nodes, signals).
**Cost:** ✓ free
**Account:** none
*Last checked: 2026-08-20*

### Brackeys — Godot beginner tutorial
<https://www.youtube.com/watch?v=LOhfqjmasi0>
**What:** One ~77-minute video building a complete first game, from a famously clear teacher.
**Cost:** ✓ free
**Account:** none to watch
**Fit:** For single-linear-video learners.
*Last checked: 2026-08-20*

## Unity

### Unity Learn — Essentials pathway
<https://learn.unity.com/pathway/unity-essentials>
**What:** The official free beginner pathway.
**Cost:** ✓ free
**Account:** optional to browse; Unity ID needed for progress-tracking (and the editor itself requires one regardless — see [unity.md](../05-game-engines/unity.md))
**Fit:** Structured, official; expect sign-in nudges.
*Last checked: 2026-08-20*

### Code Monkey — free courses
<https://unitycodemonkey.com/freecourses.php>

**Cost:** ✓ free
**Account:** none
*Last checked: 2026-08-20*

### Unity Manual
<https://docs.unity3d.com/Manual/index.html>
**What:** Official reference documentation.
**Cost:** ✓ free
**Account:** none to read
*Last checked: 2026-08-20*
