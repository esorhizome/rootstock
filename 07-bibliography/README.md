# 07 · Bibliography

The link library: places to learn from that are **free** (or precisely-flagged freemium), **legally hosted**, and — wherever possible — **usable without creating an account**. Every entry says what it is, what it costs, what it demands, and how it fits readers with ADHD, memory difficulties, or dysgraphia. Every entry carries a *last checked* date, because links rot and honesty requires timestamps.

This library is also the staging ground for the in-game bibliographies planned for the games (see [06-games-connections](../06-games-connections/README.md)) — same standards, same ritual.

## The flags

| Flag | Meaning |
|---|---|
| ✓ | Free entirely. |
| ◐ | Freemium — what's free is stated precisely, never vaguely. |
| ⚠ | Account required for meaningful use. Included only when the resource earns it, always flagged. |
| ⌛ | Archived or unmaintained — still working, still worth reading. |
| ✗ | Removed — kept visibly as a tombstone with reason and date, never silently deleted. |

## Standards for inclusion

A resource enters this library when it is free or honestly-freemium, legally hosted (official sites and open-licensed copies; nothing pirated, however convenient), and gentle in format — interactive things to click, short chunks, plain language, and no handwriting demanded anywhere. Account-optional is strongly preferred; an account-required resource must be unusually good to earn its ⚠ place. New entries use [the template](../08-templates/bibliography-entry-template.md).

## The re-checking ritual

Links are living things; this library stays trustworthy through a small seasonal ceremony — quarterly-ish, or before any game ships a bibliography drawn from here:

1. Open each link. Working and unchanged → update its *last checked* date. Done is done.
2. Moved → follow to the new home, update the URL, note the move.
3. Paywalled or account-walled since last visit → update its flag honestly; demote or remove if it no longer meets standards.
4. Dead or compromised → **do not silently delete.** Move the entry to the shelf's *Resting* section with the reason and date. Resting entries sometimes return (sites get repaired); the tombstone preserves the memory of what was good so it can be re-checked or replaced deliberately.

The ritual already has one worked example: **kobakant.at**, the beloved e-textile reference, was found serving injected spam on 2026-08-19 and rests, with its reason, at the bottom of [e-fashion.md](e-fashion.md). That is the ritual working as designed — the library said something true instead of something convenient.
