# Bibliography · Programming maths

Flags: ✓ free · ◐ freemium · ⚠ account required · ⌛ archived · ✗ resting. Legend and ritual in [README.md](README.md).

## The essentials

### Red Blob Games
<https://www.redblobgames.com/>
**What:** Amit Patel's interactive visual explanations of game maths and algorithms — grids, hexagons, pathfinding, probability, noise.
**Cost:** ✓ free entirely, no ads
**Account:** none
**Fit:** The finest interactive game-maths writing on the web; every concept is a thing you drag until it makes sense.
**Caveat:** Some pages include short code snippets — skimmable without loss.
*Last checked: 2026-08-19*

### easings.net
<https://easings.net/>
**What:** A gallery of thirty easing functions, each as a live animation with copyable JS/CSS.
**Cost:** ✓ free entirely
**Account:** none
**Fit:** Near-zero reading; pure watching. The companion to [the lerp page](../02-programming-maths/03-lerp-the-quiet-workhorse.md).
*Last checked: 2026-08-19*

### Freya Holmér — "Math for Game Devs" (YouTube)
<https://www.youtube.com/@acegikmo>
**What:** A working game-tool developer's genuinely loving video course on vectors, dot products, transforms — taught to real game-dev students.
**Cost:** ✓ free to watch
**Account:** none
**Fit:** Exceptional visual style; watch the "Math for Game Devs [2022]" playlist specifically.
**Caveat:** The channel's shader/spline content runs far past beginner — that's for later years, not a wall.
*Last checked: 2026-08-19*

## Creative coding — maths by making things move

### The Nature of Code
<https://natureofcode.com/>
**What:** Daniel Shiffman's full book on simulating nature — forces, oscillation, particles — in JavaScript (p5.js), with live embedded sketches.
**Cost:** ✓ free online (openly licensed; print sold separately)
**Account:** none
**Fit:** Warm voice, runnable examples; chapters are long, so visit sectionwise.
*Last checked: 2026-08-19*

### The Coding Train
<https://thecodingtrain.com/>
**What:** Shiffman's video universe — beginner creative coding, taught with unfiltered delight.
**Cost:** ✓ free (memberships buy perks, never content)
**Account:** none
**Fit:** High-energy video suits some ADHD days perfectly and overwhelms others — self-dose honestly.
*Last checked: 2026-08-19*

## Deeper shelves

### 3Blue1Brown — Essence of Linear Algebra
<https://www.3blue1brown.com/>
**What:** The animated series that makes vectors and matrices *visible*; the standard prelude to serious game maths.
**Cost:** ✓ free entirely
**Account:** none
**Fit:** Second-touch material — best after branch 02's vectors page exists and has been met once.
*Last checked: 2026-08-19*

### Game Math (Dunn & Parberry)
<https://gamemath.com/>
**What:** The complete "3D Math Primer for Graphics and Game Development," readable free online.
**Cost:** ✓ free online
**Account:** none
**Fit:** A dense professional reference — the shelf you consult in year three, not week three.
*Last checked: 2026-08-19*

### The Book of Shaders
<https://thebookofshaders.com/>
**What:** Interactive guide to fragment shaders — the maths of made-of-light imagery — with live editable code.
**Cost:** ✓ free (donation-optional)
**Account:** none
**Fit:** Gorgeous and interactive, and a genuine stretch: shader-land sits well past 2D game basics. Filed under someday-sparkle.
*Last checked: 2026-08-19*
